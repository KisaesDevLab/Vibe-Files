# Keyboard shortcuts

Every keyboard shortcut in Vibe Files, by tab. Keys that act on a list or the tape work only when you are not typing in a text box.

## Everywhere

- F1 — open Help.
- Ctrl and + — larger text (same as **A+** in the header).
- Ctrl and - — smaller text (same as **A-**).
- Ctrl and 0 — text back to 100%.

## Browse: the document grid

Click a row in the grid first; these keys then work as long as no text box (such as **Filter this folder**) has the cursor.

- Down arrow / Up arrow — move to the next or previous document. The preview follows.
- Shift and Down arrow / Up arrow — extend the selection.
- Home / End — first or last document in the list.
- Space — add the current document to the selection, or take it out.
- Ctrl and A — select every document in the list.
- Esc — clear the selection.
- Enter — open the current document (a PDF opens in the Viewer; other files in their own program).
- Ctrl and Z — undo your last change (same as **Undo last**). See [Undoing changes](help:undo).

With the mouse:

- Ctrl and click — add a row to the selection, or take it out.
- Shift and click — select every row from the last one you clicked.
- Double-click — open the document.
- Right-click — **Open**, **Open in PDF app**, **Open in Explorer**, **Copy path**, **Move to trash**.
- Drag rows onto a folder in the tree — move them there. See [Moving, renaming and deleting](help:moving-renaming).

## Intake

On the Intake tab, when you are not typing and no dialog is open:

- Enter (on **Preview**) — same as clicking the commit button (such as **Commit 8 files**): opens the summary. Filing still needs your click to confirm.
- Delete (on **Preview**) — skip the row under the mouse pointer, or un-skip it.
- Ctrl and Z — goes to **History** and asks whether to undo the last batch (**Undo last batch**).
- While editing a file's new name on **Preview**: Enter keeps it, Esc cancels.

See [Intake](help:intake).

## Viewer

- In **Find**, Enter searches the document for the words typed.
- In **Go to**, type a page number and press Enter.

### The ten-key tape

With the **10-key** tab open and no text box in use, the keyboard drives the tape:

- 0 to 9 and . — type an amount.
- + - * / = — the operation keys.
- Enter — adds (same as +).
- Backspace — removes the last digit typed.
- Delete — clears the amount being typed.
- Esc — stops picking an amount off the page, or placing the tape.
- Ctrl and Z — undo the last tape key. Ctrl, Shift and Z — redo it.

See [The ten-key tape](help:ten-key).

## Dialogs and boxes

- On **Admin is locked**, Enter in **Admin password** is the same as clicking **Unlock**. See [Admin password](help:admin-password).
- In print capture's test box, Enter is the same as clicking **Try**. See [Print capture](help:print-capture).
